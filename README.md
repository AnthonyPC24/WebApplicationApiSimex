# Plataforma de Gestión Logística Internacional - API Backend 🌐⚙️

Este repositorio contiene la **API REST** central de la Plataforma de Gestión Logística Internacional. 
Su función principal es servir como núcleo del backend, conectando de forma segura la base de datos relacional con las diferentes aplicaciones del ecosistema y
gestionando el control de acceso de los usuarios.

## 🚀 Funcionalidades Principales (Este Repositorio)
* **Gestión de Usuarios y Seguridad:** Control de acceso, autenticación y administración de perfiles de usuario.
* **API RESTful:** Arquitectura backend diseñada para gestionar flujos de trabajo logísticos e intercambiar información de forma eficiente mediante endpoints optimizados.
* **Persistencia de Datos:** Conexión y comunicación robusta con la base de datos para garantizar la integridad de las operaciones logísticas.
* **Análisis Funcional:** Estructura de base de datos relacional modelada exhaustivamente mediante diagramas UML antes de su desarrollo.

## 🛠️ Tecnologías utilizadas
* **Lenguaje:** C# 
* **Framework:** .NET 
* **Base de Datos:** SQL Server 
* **Entorno de Desarrollo:** Visual Studio / Windows

## 📱 Componentes con los que se integra
Para el funcionamiento global de la plataforma, esta API se comunica con:
* **Aplicación Móvil (Android):** Desarrollada en Kotlin con Retrofit para el consumo de estos endpoints en tiempo real.
* **Módulos ERP:** Integración de procesos empresariales y logística avanzada mediante Odoo (Python).
